这里是「**图解 Codex**」专栏，从日常使用到源码架构，带你理解 Codex 怎么完成任务，以及怎样把它用在自己的项目里。无论是想把项目规则和工具配置好，还是准备面试中的 Agent 原理题，都可以从下面三个方向开始：

- **基础入门**：认识 `AGENTS.md`、Skills、Subagents、MCP 和 Hooks，掌握 Codex 的工程化能力。
- **实践技巧**：调整提示词和项目规则，明确任务目标与完成标准，让 Codex 更顺畅地推进工作。
- **源码解析**：拆解 Harness 架构，理解 Agent 循环、上下文管理、工具执行、会话恢复和长期记忆。

建议先读基础入门，了解各项能力的用途；再看实践技巧，调整自己的使用方式；最后进入源码解析，理解这些能力背后的实现。
