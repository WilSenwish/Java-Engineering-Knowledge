# RAG 面试题 7：Embedding 有哪几种算法你了解过吗？

## 核心答案

三代演进：**静态词向量**（Word2Vec/GloVe，一词一向量，处理不了多义词）→ **上下文相关向量**（ELMo/BERT，同词不同上下文不同向量，但检索需两两拼接，百万文档跑百万次不可用）→ **句子级对比学习 Embedding**（SBERT/SimCSE/BGE，bi-encoder 独立编码 + 余弦相似度，提前算好存起来，RAG 标配）。演进逻辑：每一代补上一代的坑。

## 第一代：静态词向量

- **Word2Vec**（Google 2013）：CBOW（周围词预测中心词）/ Skip-gram（中心词预测周围词）。Skip-gram 更常用——从一个词产生多个训练样本，对低频词友好。「国王-男人+女人≈女王」即其成果；
- **GloVe**（斯坦福）：对全局词共现矩阵分解，效果与 Word2Vec 接近可互换；
- **FastText**（Facebook）：词拆字符级 n-gram 子词，解决未登录词（新词/专有名词/网络流行语）——子片段见过就能估出合理向量；
- **共同局限：静态**。「我吃了苹果」和「苹果手机发布了」的「苹果」向量完全相同——它只是记住「哪些词经常一起出现」，不是真理解语义。

## 第二代：上下文相关向量

- **ELMo**（2018）：双向 LSTM，两个方向隐藏状态拼接；
- **BERT**（2018）：Transformer + Masked LM，[CLS] 表全句，双向；
- **检索场景致命缺陷**：比较两个句子必须拼在一起喂 BERT 让 [CLS] 判断——百万文档跑百万次，单次数十毫秒 = 几小时，用户等不起。这直接催生第三代。

## 第三代：句子级对比学习

- **SBERT**（2019）：bi-encoder 两句子独立编码各自得向量，只用余弦比。牺牲 token 间交叉关系（Cross-Encoder 深度交互）换速度数量级提升——文档向量提前算好，检索只算一次查询向量；
- **SimCSE**（2021）：同一句话两次 dropout 得两向量作正样本对拉近，batch 内其他句作负样本推远。解决 BERT 原生句子向量「各向异性」（挤在窄锥形区没充分利用空间），把向量空间「撑开」；
- **BGE**（智源）：中文 RAG 流行开源，对比学习大规模中英训练，支持 bi-encoder + reranker 双形态；
- **E5**（微软）：常用英文对比学习 Embedding。

## 新趋势（第三代基础上的增强）

- **指令感知 Embedding**（Qwen3-Embedding）：按检索指令动态调整向量——「找相似问题」vs「找答案」不同意图不同向量；
- **Matryoshka 表示学习（MRL）**：前 N 维即表达有意义语义，可截断维度平衡精度与存储；
- **多模态 Embedding**：同模型编码文本+图片，跨模态检索。
