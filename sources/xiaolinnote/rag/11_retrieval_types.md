# RAG 面试题 11：请你介绍一下向量检索和关键词检索的区别？

## 核心答案

两者各有盲区且恰好互补。**BM25 关键词检索**靠词频统计（TF×IDF，倒排索引），精确命中极强（产品型号「iPhone 15 Pro Max」、专有名词「LSTM」），但同义词没辙（查「手机截图」文档写「iPhone 截屏教程」零重叠直接忽略）。**向量检索**靠语义空间距离，跨同义词/近义词/表达方式（「苹果手机怎么截图」vs「iPhone 如何截屏」余弦可达 0.95），但精确词容易漏（「M4 Pro」被和「苹果最新处理器」拉近反而找不到字面记录）。**结论不是二选一，是混合检索：两路并行 + RRF 融合**。

## BM25 细节

- 打分两因素：**词频 TF**（词在文档出现次数）+ **稀缺度 IDF**（词在语料的罕见程度）——「的」「是」哪都高频，只看词频所有文档都高分，IDF 给常见词降权罕见词加权；
- BM25 在 TF-IDF 基础上加**饱和度限制**，防某词重复太多次权重无限叠加；
- 中文需先分词（jieba）再建索引。

## 混合检索：RRF

为什么不能原始分数加权平均：向量相似度（0~1 余弦）和 BM25 分数（任意正数）**量纲完全不同**，像摄氏度和华氏度直接加没意义。归一化也不稳（各路分数分布差异大）。

**RRF 只用排名**：`score(doc) = Σ 1/(rank + k)`，k 平滑参数通常 60。排名越靠前倒数越大；两路都高排的文档综合分高，只有一路命中的也不会被完全丢掉。好处：无需训练、计算量极小；且**两路可并行执行，总延迟取最大值而非相加**——几乎没有额外时间代价，召回质量明显更好。生产 RAG 很少只用纯向量，混合检索已是行业默认。
