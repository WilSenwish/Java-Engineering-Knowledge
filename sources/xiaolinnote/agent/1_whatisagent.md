## 核心答案：自主闭环

Agent 本质上是一个能**自主完成目标**的 AI 系统。与传统 AI 最核心的区别在于「**自主性**」和「**能行动**」。传统 AI 是问一句答一句的被动响应；Agent 有自己的规划能力，给它一个复杂目标，它自己把任务拆成多步，通过调工具、访问记忆、感知环境一步步执行，直到完成。**它不只是输出文字，而是真的能做事。**

## 普通大模型的三大局限（一环扣一环）

1. **知识被冻结**：训练数据有截止日期，问今天的天气/最新股价完全不知道（比喻：毕业后再也不看新闻的人）；
2. **不能行动**：本质是文本生成器，能写出完美邮件正文，但点不了「发送」按钮；
3. **没有持续状态**：每次调用之间完全失忆，不手动传上下文就不记得上一轮。

## Agent 的三件核心支撑

1. **工具调用（Tool Use）**——从「说话」到「做事」的关键。**关键认知：不是模型自己执行，而是模型「告诉你该调什么」，你的代码去真正执行，结果再反馈给模型。模型始终只是大脑，不是手脚**（决策与执行分离）。工具定义只有「名字、描述、需要哪些参数」，本质是一份说明书。工具调用一举突破三大局限：接搜索引擎解决知识冻结、接 API/代码执行器解决不能行动。
2. **记忆机制**——短期记忆（当前任务中间状态，存上下文）+ 长期记忆（跨任务，向量数据库存储、语义检索）。保证复杂任务执行连贯性。
3. **多步推理和自我纠错**——某步失败不崩掉，而是感知失败、分析原因、换方式重试（关键词 A 没搜到就换 B）；还能完成一步后回头审视对不对。**「边做边反思」是 Agent 区别于简单自动化脚本的关键**。

## Agent 运行闭环

**感知 → 规划 → 行动 → 再感知**。给它目标（如「调研竞品整理成报告」），它先拆解任务，再一步步执行，每步结果反馈回来指导下一步。

## 为什么现在才爆发（三条件同时成熟）

1. 大模型能力跨过「能用」门槛（GPT-4/Claude 3 一代推理与指令遵循质变）；
2. 工具调用标准化（OpenAI 2023 Function Calling，结构化 JSON 输出调用请求）；
3. 配套生态完善（LangChain/LlamaIndex 降低门槛、向量数据库解决长期记忆、API 服务丰富）。

## 生态两大协议（面试高频）

- **MCP（Model Context Protocol，Anthropic 2024.11）**：Agent 工具世界的「USB-C 接口」。没有 MCP 时 M 个框架 × N 个工具 = M×N 套适配代码；MCP 定义标准 JSON-RPC 协议，工具方按标准暴露能力（MCP Server），任何支持 MCP 的 Agent（内置 MCP Client）直接发现和调用。三层架构：**Host**（用户交互的 AI 应用，如 Claude Desktop/Cursor）→ **Client**（管理与 Server 的连接通信）→ **Server**（暴露工具能力的服务）。2025.12 Anthropic 将 MCP 捐给 Linux 基金会旗下 Agentic AI Foundation（AAIF），已有数千个公开 MCP Server。
- **A2A（Agent2Agent，Google 2025.4）**：解决「Agent 怎么和另一个 Agent 协作」。核心设计 **Agent Card**（每个 Agent 的「名片」：能做什么、正在做什么、需要什么输入）。2025.6 捐给 Linux 基金会，SAP/Salesforce/ServiceNow 接入。
- **关系**：MCP 管 Agent↔工具连接，A2A 管 Agent↔Agent 通信，互补，各管一层。

## 面试翻车点（三个雷）

1. 把 Agent 等同于「插件」或「工具调用」——工具调用只是 Agent 能力的一部分；
2. 停在「能调工具」这层，没点出**自主性**——关键不是「有工具」，而是「自己决定用不用、什么时候用、用哪个」；
3. 忽略执行闭环——感知→规划→行动→再感知才是核心机制。

**答题三要素**：① 自主规划（复杂目标自己拆多步）；② 能行动（工具调用与外部世界真实交互）；③ 有闭环（每步结果反馈指导下步）。补一句：模型只是大脑，真正执行是你的代码。
